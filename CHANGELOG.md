# Changelog

All notable changes to the **Smart Dialer & Caller ID** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-08

### Added
- **Smart T9 Keypad:** Alphanumeric name and digit live contact matching engine with audio DTMF tones and vibration haptic feedback.
- **Real-Time Caller ID:** Live floating incoming call HUD showing caller identity, avatar, verification status, and carrier info.
- **Telecom Operator Detection:** Full carrier prefix recognition for Bangladesh (Grameenphone, Banglalink, Robi, Airtel, Teletalk) and international dialing formats.
- **Spam Shield:** Community fraud database, one-tap spam report submission, and auto-block toggle for known scammers (OTP phishing, fake bank agents).
- **Call Logs & Recents:** Filter chips (All, Missed, Incoming, Outgoing, Blocked), search bar, and detailed call inspector dialog.
- **Call Telemetry & Analytics:** Total call duration metrics, talk time counter, call ratio breakdown, and top frequent callers.
- **Contacts Management:** Alphabetical contacts directory, favorites carousel, and contact creator.
- **Bilingual Interface:** One-click instant toggle between English and বাংলা (Bengali).
- **CI/CD:** Automated GitHub Actions pipeline for tests and GitHub Release generation.
